SessionDock 3.1.0

Aprobación de la publicación

- SessionDock 3.1.0 levanta el bloqueo de distribución sin activos del 04/08/2026 únicamente cuando la publicación oficial de GitHub ha superado el borrador protegido, el análisis de Defender y la prueba como usuario estándar en un portátil independiente, la aprobación independiente de publicación, la publicación y las comprobaciones de redescarga pública.
- SessionDock sigue siendo un proyecto personal sin firma. Cualquier detección antivirus con un nombre de amenaza específico obliga a detener la distribución y el uso. La descarga manual admitida es el ZIP portátil completo y transparente para Windows x64 de la publicación oficial de GitHub, nunca un ejecutable aislado ni un archivo adjunto de Discord.

Sesiones completas desde una sola pantalla de inicio

- El inicio rediseñado mantiene visibles Iniciar cuentas, Ejecutar plantilla, Macros y Plantillas, con acciones directas para Destinos y Administrar cuentas debajo. Las herramientas avanzadas siguen disponibles en Configuración.
- Cada destino reutilizable guardado debe tener un nombre, puede asignarse a cuentas y permanece sincronizado entre las páginas de configuración específicas, el espacio avanzado, los inicios por lotes y el editor de plantillas. Los destinos personalizados por cuenta siguen admitidos.
- Las plantillas ahora reúnen las cuentas seleccionadas, sus destinos, posiciones de ventana adaptables, tiempos de inicio y asignaciones de macros ExactWheel. Los datos existentes de plantillas e inicios siguen siendo legibles y se actualizan de forma conservadora.
- La exportación portátil ampliada puede incluir macros, destinos públicos aptos, plantillas y preajustes de inicio por lotes seleccionados; sus dependencias se tienen en cuenta durante la importación. Se excluyen inicios de sesión, cookies, tokens, tickets, nombres de usuario, claves y rutas de cuentas locales, datos de servidores privados, integraciones y registros. Los nombres seleccionados y los identificadores numéricos de Roblox pueden seguir siendo datos personales. Los archivos de macro se copian byte por byte y pueden contener secretos escritos; las macros con teclado se enumeran por separado y requieren una confirmación explícita.
- El inicio por lotes puede colocar los clientes de Roblox en una escalera configurable con zonas de enfoque fáciles de pulsar. Los diseños guardados usan una identidad estable del monitor y coordenadas relativas. Las posiciones guardadas y macros relativas al cliente se adaptan a geometrías de pantalla compatibles; una asignación de macro para todo el diseño permanece sin asignar para su revisión cuando su topología de monitores es incompatible.

Macros ExactWheel integradas en SessionDock

- ExactWheel se incluye como componente inspeccionable en el mismo paquete de SessionDock. El usuario puede grabar una macro para el cliente enfocado o para todo el diseño, elegir un atajo de teclado global personalizable para detener la grabación, administrar la biblioteca y asignar una macro a varios clientes.
- Las macros se repiten hasta que el usuario pulsa explícitamente Detener, cierra el controlador, inicia un lote de reemplazo o sale de SessionDock. La pérdida de foco de Roblox, una ventana objetivo temporalmente no disponible, la protección frente a entradas físicas o un cliente lento provocan una pausa sin inyectar entradas y un reintento cuando vuelve a ser seguro, en lugar de informar silenciosamente que la ejecución terminó.
- Pequeñas pausas acotadas al cambiar el foco evitan que las entradas choquen entre clientes. Las velocidades seleccionables conservan el orden de teclas, botones, arrastres, clics, rueda y pulsaciones mantenidas incluso después de un retraso de temporización.
- La preparación y reproducción de macros se ejecutan fuera del hilo de interfaz WPF cuando es posible, mientras se limita la frecuencia del progreso mostrado por el controlador. Las vinculaciones verificadas de Roblox reutilizadas, cachés acotadas, instantáneas compartidas de ventanas y pantallas, rutas críticas sin asignaciones de memoria y suspensión del navegador inactivo reducen la carga de CPU y memoria por cliente.
- Las ventanas de Roblox se organizan sin obligar a que otras aplicaciones permanezcan detrás. Las comprobaciones del proceso exacto, propiedad del HWND, primer plano, puntero, limpieza de entrada inyectada y entrada física siguen activas al enviar cada acción.

Configuración guiada y fiabilidad

- El primer inicio ofrece una guía básica para añadir cuentas, nombrar destinos, iniciar, guardar diseños, grabar macros y ejecutar plantillas, además de un recorrido avanzado independiente para las funciones menos habituales.
- En ventanas pequeñas, las tarjetas del tutorial se colocan alrededor del control resaltado. Los controles resaltados que quedan fuera de pantalla o recortados por el desplazamiento usan geometría segura y sus actualizaciones se aplazan y agrupan, por lo que el recorrido avanzado ya no se bloquea ni se cierra al iniciar, desplazarse, avanzar o retroceder.
- Las listas de cuentas en modo oscuro, la sincronización de destinos, la edición de plantillas, el tamaño del controlador de macros, el foco durante la grabación y la reproducción continua de todo el diseño recibieron correcciones adicionales.

Paquete integrado transparente

- HandleScope sigue incluido con SessionDock y no necesita un instalador, un script de PowerShell ni un cambio de directiva de ejecución por separado. El proyecto HandleScope sigue disponible de forma independiente y se siguen admitiendo las opciones revisadas de compatibilidad con la versión independiente.
- La versión no contiene un programa Setup, un paquete de un solo archivo, un autoextractor ni firma Authenticode para los archivos ejecutables propios de SessionDock. El ZIP portátil presenta por separado los componentes de la aplicación y los archivos del entorno de ejecución de Microsoft para su inspección y análisis.
- La publicación protegida vincula el ZIP portátil y el paquete completo reservado a actualizaciones con los mismos bytes de aplicación, metadatos de actualización firmados, catálogo HandleScope ligado a la versión, sumas de comprobación completas, SBOM SPDX, procedencia fijada de ExactWheel y HandleScope, comprobaciones de firmas de Microsoft, análisis de Defender y atestaciones de artefactos de GitHub.
