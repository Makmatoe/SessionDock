SessionDock 2.7.6

Installation fiable de HandleScope

- La configuration gérée est désormais épinglée sur la nouvelle version immuable HandleScope v0.1.4, dont le contrat autorise explicitement le flux confirmé séparément d’installation, de démarrage et de démarrage automatique en tant qu’utilisateur standard. La confirmation indique maintenant qu’une ancienne installation compatible de l’utilisateur peut être remplacée ; l’activation de l’intégration reste distincte.
- Le programme d’installation vérifié de HandleScope v0.1.4 fonctionne désormais avec la stratégie PowerShell Restricted par défaut de Windows en utilisant RemoteSigned uniquement pour le processus enfant contrôlé. SessionDock n’utilise toujours jamais Bypass ni Unrestricted, ne modifie aucune stratégie enregistrée, ne remplace pas la stratégie de groupe, n’élève pas les privilèges et n’active pas automatiquement l’intégration.
- Les ressources GitHub épinglées exactes livrées sans en-tête Content-Length sont désormais validées au lieu d’être refusées prématurément. Les longueurs déclarées incohérentes, les tailles ou empreintes incorrectes, les échecs de somme de contrôle, les structures ZIP non sûres et les modifications de l’inventaire interne sont toujours refusés de manière sûre.
- Les échecs d’installation affichent maintenant une catégorie sûre localisée et le guide de configuration officiel, afin de rendre les problèmes de stratégie, de réseau, d’intégrité, d’environnement et de cycle de vie exploitables sans exposer de détails internes ni exécuter de code non vérifié.
- La création des paquets de version gère désormais en toute sécurité les créations concurrentes dans le système de fichiers avant la vérification des artefacts immuables.
