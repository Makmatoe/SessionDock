SessionDock 2.7.6

Zuverlässige HandleScope-Installation

- Die verwaltete Einrichtung ist jetzt an die neu veröffentlichte unveränderliche HandleScope-Version v0.1.4 gebunden, deren Vertrag den separat bestätigten Ablauf für Installation, Start und Autostart als Standardbenutzer ausdrücklich erlaubt. Die Bestätigung weist nun darauf hin, dass eine ältere unterstützte benutzerspezifische Installation ersetzt werden kann; die Aktivierung der Integration bleibt getrennt.
- Das verifizierte Installationsprogramm für HandleScope v0.1.4 funktioniert jetzt mit der Windows-Standardeinstellung Restricted für PowerShell, indem RemoteSigned nur für den geprüften untergeordneten Prozess verwendet wird. SessionDock verwendet weiterhin nie Bypass oder Unrestricted, ändert keine gespeicherten Richtlinien, setzt keine Gruppenrichtlinien außer Kraft, fordert keine erhöhten Rechte an und aktiviert die Integration nicht automatisch.
- Exakt festgelegte GitHub-Assets ohne Content-Length-Header werden jetzt validiert statt vorzeitig abgelehnt. Abweichende angegebene Längen, falsche Inhaltsgrößen oder Hashes, Prüfsummenfehler, unsichere ZIP-Strukturen und Änderungen an der internen Dateiliste werden weiterhin sicher abgewiesen.
- Installationsfehler zeigen jetzt eine lokalisierte sichere Kategorie und die offizielle Einrichtungsanleitung, sodass Richtlinien-, Netzwerk-, Integritäts-, Umgebungs- und Lebenszyklusprobleme behoben werden können, ohne interne Details offenzulegen oder ungeprüften Code auszuführen.
- Die Release-Paketierung verarbeitet konkurrierende Dateisystemerstellungen jetzt sicher, bevor unveränderliche Artefakte verifiziert werden.
