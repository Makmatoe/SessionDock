SessionDock 3.1.0

Distribution approval

- SessionDock 3.1.0 lifts the zero-asset distribution hold dated 2026-08-04 only when the canonical GitHub release has completed the protected-draft, separate-laptop Defender scan and standard-user smoke test, independent publication approval, publication, and public re-download gates successfully.
- SessionDock remains an unsigned passion project. A named antivirus detection is still a hard stop. The supported manual download is the complete transparent Windows x64 portable ZIP from the canonical GitHub release, never a bare executable or Discord attachment.

Complete sessions from one home screen

- The redesigned Home workspace keeps Launch accounts, Run template, Macros, and Templates prominent, with direct Destinations and Manage accounts actions beneath them. Advanced tools remain available in Settings.
- Every saved reusable destination requires a name, can be assigned to accounts, and stays synchronized between the focused setup pages, advanced workspace, batch launches, and template editor. Custom per-account destinations remain supported.
- Templates now combine selected accounts, their destination assignments, scalable window positions, launch timing, and ExactWheel macro assignments. Existing template and launch data remains readable and is upgraded conservatively.
- The richer portable export can include selected macros, eligible public destinations, templates, and launch presets with dependency-aware import. It excludes sign-ins, cookies, tokens, tickets, usernames, local account keys and paths, private-server material, integrations, and logs. Selected names and numeric Roblox IDs can still be personal data. Macro files are copied byte for byte and can contain typed secrets, so keyboard-bearing macros are listed separately and require an explicit acknowledgement.
- Batch launch can arrange Roblox clients in a configurable staircase with clearly exposed focus areas. Saved layouts use stable monitor identity and relative coordinates. Saved positions and client-relative macros adapt across compatible display geometry; a whole-layout macro assignment remains unassigned for review when its monitor topology is incompatible.

ExactWheel macros built into SessionDock

- ExactWheel is included as an inspectable component in the same SessionDock package. Users can record a focused-client macro or a whole-layout macro, choose a customizable global recording-stop key, manage the macro library, and assign one macro to several clients.
- Macro playback loops continuously until the user explicitly presses Stop, closes the controller, starts a replacement batch, or exits SessionDock. Losing Roblox focus, a temporarily unavailable target, physical-input safety, or a slow client pauses without injecting and retries when safe instead of silently reporting a completed run.
- Small bounded focus-settling gaps keep inputs from colliding while switching clients. Selectable playback speeds preserve key, button, drag, click, wheel, and hold ordering even after timing stalls.
- Macro preparation and playback run off the WPF UI thread where practical, while controller progress is throttled. Retained verified Roblox leases, bounded caches, shared window and display snapshots, allocation-free hot paths, and suspension of idle browser work reduce per-client CPU and memory overhead.
- Roblox windows are arranged without forcing unrelated applications permanently behind them. Exact process, HWND ownership, foreground, pointer, injected-input cleanup, and physical-input checks remain enforced at dispatch boundaries.

Guided setup and reliability

- First launch now provides a focused get-started tutorial for adding accounts, naming destinations, launching, saving layouts, recording macros, and running templates, plus a separate advanced tour for less common controls.
- Tutorial cards reposition around highlighted controls on smaller windows. Off-screen and clipped targets use safe geometry, and spotlight work is deferred and coalesced so the advanced tour no longer freezes or crashes during scrolling, startup, Next, or Back.
- Dark-mode account lists, destination synchronization, template editing, macro-controller sizing, recording focus behavior, and continuous whole-layout playback received additional fixes.

Transparent integrated package

- HandleScope remains included with SessionDock and no longer needs a separate installer, PowerShell script, or execution-policy change. The independently available HandleScope project and reviewed standalone compatibility choices remain supported.
- The release has no Setup executable, single-file bundle, self-extractor, or executable signing. The portable ZIP exposes application components and Microsoft runtime files separately for scanning and inspection.
- The protected release binds the portable ZIP and update-only full package to the same application bytes, signed update metadata, version-bound HandleScope catalog, complete checksums, SPDX SBOM, pinned ExactWheel and HandleScope provenance, Microsoft-signature checks, Defender scans, and GitHub attestations.
