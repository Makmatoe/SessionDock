SessionDock 2.9.0

Installation de HandleScope indépendante de la stratégie PowerShell

- SessionDock comprend désormais un adaptateur d’installation natif et fermé pour HandleScope. Une version du catalogue signé déclarant la capacité native révisée peut uniquement lancer l’exécutable fixe api/HandleScope.Setup.exe avec les phases de vérification et d’installation compilées ; les données du catalogue ne peuvent toujours fournir ni chemin, ni commande, ni argument, ni point de terminaison.
- L’installation native exige un manifeste de version 2 épinglé par le catalogue, avec le chemin, la taille et le SHA-256 exacts de l’exécutable d’installation. Avant les deux phases, SessionDock compare cette identité au fichier extrait verrouillé et à l’inventaire interne complet.
- Le catalogue de compatibilité intégré recommande désormais la version publique immuable HandleScope 0.3.0, vérifiée indépendamment. Les choix Automatique, Conserver la version installée, environnement exact et API automatique/v1/v2 restent inchangés.
- Les versions HandleScope 0.1.4 et 0.2.2 révisées conservent leur adaptateur Windows PowerShell RemoteSigned fixe pour la rétrocompatibilité. L’installation native n’appelle pas PowerShell et ne modifie aucune stratégie d’exécution ; aucun chemin n’élève les privilèges, n’installe silencieusement, ne rétrograde ou n’active l’intégration.
