SessionDock 3.1.3

Actualizaciones fiables sin falsos errores de seguridad

- El botón Actualizar de una copia portátil ahora abre la publicación más reciente y canónica de GitHub, de modo que la descarga admitida, la suma y las notas están a un clic. Las actualizaciones portátiles siguen usando una carpeta recién extraída y nunca sobrescriben la aplicación en ejecución.
- Una actualización instalada pendiente ya no falla solo porque Velopack omita su valor SHA-256 después de descargarla. SessionDock mide y calcula el hash del NUPKG local y después exige que esos bytes exactos coincidan con el descriptor firmado por la clave de publicación de SessionDock incorporada.
- La validación actual del NUPKG acepta la carga completa y transparente creada por el flujo protegido, en vez de suponer un archivo pequeño y obsoleto. Comprueba la identidad y el hash firmados, una estructura de archivo acotada, rutas normalizadas seguras, nombres únicos en Windows, metadatos de paquete seguros, entradas canónicas de directorio vacío, metadatos y archivos de inicio necesarios para funcionar, versión, canal y formato ejecutable.
- Los daños, la manipulación, las versiones anteriores, las firmas o hashes distintos, las rutas inseguras o duplicadas, los puntos de análisis, los dispositivos y otras entradas no normales, los directorios no canónicos, la ausencia de elementos operativos esenciales, demasiadas entradas, una expansión excesiva y el contenido ejecutable no válido siguen bloqueándose de forma segura. El verificador protegido de la publicación rechaza por separado cargas ejecutables o de instalación inesperadas y demuestra el inventario exacto del candidato.

Ruta de recuperación clara

- Una versión instalada antigua que ya califica un paquete completo oficial como inseguro no puede sustituir su propio verificador defectuoso. Conserve sus datos locales, descargue de GitHub el ZIP portátil verificado de esta versión, extráigalo en una carpeta nueva y ejecute esa copia con el mismo usuario de Windows. No extraiga el NUPKG ni copie archivos encima de la instalación antigua.
- SessionDock sigue siendo un proyecto personal sin firma. Editor desconocido es una advertencia de reputación, pero una detección antivirus con nombre sigue siendo una parada obligatoria y nunca queda anulada por una suma, un descriptor ni este cambio del actualizador.
