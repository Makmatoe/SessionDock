SessionDock 3.1.3

Reliable updates without false safety failures

- The Update button in a portable copy now opens the canonical latest GitHub release so the supported download, checksum, and release notes are one click away. Portable updates still use a newly extracted folder and never overwrite the running application.
- A pending installed update no longer fails merely because Velopack omitted its SHA-256 value after download. SessionDock measures and hashes the local NUPKG, then requires those exact bytes to match the descriptor signed by the pinned SessionDock release key.
- Current NUPKG validation now accepts the complete transparent application payload shipped by the protected release workflow instead of assuming an obsolete tiny archive. It checks the signed package identity and hash, bounded archive structure, safe normalized paths, unique Windows names, safe package metadata, canonical empty directory entries, operationally required metadata and launch files, version and channel binding, and executable format.
- Corruption, tampering, rollback, signature or hash mismatch, unsafe or duplicate paths, reparse points, device and other nonregular entries, noncanonical directories, missing operational essentials, excessive entry counts, excessive expansion, and invalid executable content still fail closed. The protected release verifier separately rejects unexpected executable or installation payloads and proves the exact candidate inventory.

Clear recovery path

- An older installed build that already calls an official full package unsafe cannot replace its own broken verifier. Keep its local data, download the verified portable ZIP for this release from GitHub, extract it into a new folder, and run that copy as the same Windows user. Do not unpack the NUPKG or copy files over the old installation.
- SessionDock remains an unsigned personal project. Unknown publisher is a reputation warning, but a named antivirus detection remains a hard stop and is never overridden by a checksum, descriptor, or this updater change.
